# Privacy Policy

HTTP Request Capture runs locally in the browser. Captured request data is stored in Chrome extension storage on the user's device.

The extension does not sell data, does not use third-party analytics, and does not transmit captured requests to any remote service unless the user explicitly uses export, Postman sync, or proxy replay features.

Sensitive request data such as headers, cookies, authorization values, URLs, and bodies may be captured because that is the core debugging purpose of the extension. Users should clear captured requests when they are no longer needed.
